# Практична робота № 1 Part C: Розв'язання задачі лінійного програмування зі змішаною системою обмежень

**Дисципліна:** Алгоритми систем підтримки прийняття рішень
**Виконав:** студент 3 курсу групи № 633П Коваленко М.А.

## Мета роботи
Навчитися розв’язувати задачу лінійного програмування із змішаною системою обмежень з використанням симплекс-методу.

## Функціонал програми
Для виконання практичної роботи було розроблено консольний застосунок мовою С#. Програма дозволяє на основі алгоритму модифікованих жорданових виключень (МЖВ) реалізувати такі дії:
* Автоматичне зведення системи обмежень до канонічного вигляду (обробка знаків `<=`, `>=`, та строгих рівнянь `=`).
* Введення штучних змінних («0-рядків») для строгих рівнянь та перевірка знаків вільних членів.
* Виявлення та видалення нуль-рядків (штучного базису) з динамічним викреслюванням відповідних стовпців із симплекс-таблиці.
* Пошук опорного розв'язку задачі лінійного програмування.
* Пошук оптимального розв'язку задачі лінійного програмування.
* Виведення детального згенерованого протоколу обчислень по кожному етапу.

## Структура проекту
Програма побудована за принципами ООП та розділена на три основні класи:
* **`Program`**: відповідає за керування консольним інтерфейсом, збір вхідних даних (включаючи обробку знаків рівнянь/нерівностей) та запуск обчислень.
* **`SimplexAlgorithm`**: інкапсулює математичну логіку. Містить алгоритми МЖВ, метод `EliminateZeroRows` для викреслювання 0-рядків, а також методи пошуку мінімальних відношень для опорного та оптимального розв'язків із вбудованим захистом від зациклень.
* **`ConsoleHelpers`**: містить допоміжні методи для безпечної обробки вхідних даних та форматованого виведення симплекс-таблиць на екран.

## Вхідні дані (Варіант 12)
Програма приймає на вході кількість змінних і обмежень, коефіцієнти цільової функції, а також систему обмежень. Відповідно до завдання, одне з обмежень є строгим рівнянням.

**Постановка задачі:**
`Z = -2x1 - x2 + x3 + x4 -> max`

**Система обмежень:**
```text
2x1 -  x2 + 3x3 + 4x4  = 10
 x1 +  x2 +  x3 -  x4 <= 5
 x1 + 2x2 + 2x3 + 4x4 <= 12
xj >= 0, j=1..4
```

## Приклад результату роботи програми
На виході програма генерує покроковий протокол (з відображенням симплекс-таблиць на кожній ітерації), успішно видаляє стовпці штучних змінних і видає кінцеві результати:

* **Всі нуль-рядки успішно видалено.**

* **Знайдено опорний розв’язок:**
```text
X = (5,00; 0,00; 0,00; 0,00)
```

* **Знайдено оптимальний розв’язок:**
```text
X = (0,00; 0,00; 3,33; 0,00)
```

* **Максимум функції мети:**
```text
Max (Z) = 3,33
```
