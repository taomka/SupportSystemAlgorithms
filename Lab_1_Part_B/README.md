# Практична робота № 1 (Part B): Розв'язання задачі лінійного програмування методом МЖВ

**Дисципліна:** Алгоритми систем підтримки прийняття рішень
**Виконав:** студент 3 курсу групи № 633П Коваленко М.А.

## Мета роботи
Навчитися застосовувати модифіковані жорданові виключення (МЖВ) для розв'язання задач лінійного програмування (пошук опорного та оптимального розв'язків).

## Функціонал програми
Для виконання практичної роботи було розроблено консольний застосунок мовою С#. Програма дозволяє на основі алгоритму модифікованих жорданових виключень (МЖВ) реалізувати такі дії:
* Зведення системи обмежень до канонічного вигляду (автоматична обробка знаків `>=`).
* Пошук опорного розв'язку задачі лінійного програмування.
* Пошук оптимального розв'язку задачі лінійного програмування (як для максимізації, так і для мінімізації функції мети).
* Виведення детального згенерованого протоколу обчислень по кожному кроку МЖВ.
* Захист від зациклення алгоритму та перевірка на суперечливість системи або необмеженість цільової функції.

## Структура проекту
Програма побудована за принципами ООП та розділена на три основні класи:
* **`Program`**: відповідає за керування консольним інтерфейсом, збір вхідних даних та запуск обчислень.
* **`SimplexAlgorithm`**: інкапсулює математичну логіку (алгоритми МЖВ, пошук мінімальних відношень для опорного та оптимального розв'язків).
* **`ConsoleHelpers`**: містить допоміжні методи для безпечної обробки вхідних даних (запобігає крашам при опечатках) та форматованого виведення симплекс-таблиць на екран.

## Вхідні дані (Варіант 12)
Програма приймає на вході кількість змінних і обмежень, коефіцієнти цільової функції, а також систему обмежень. Відповідно до завдання, знак другого обмеження було змінено на протилежний (`>=`). 

**Постановка задачі:**
`Z = -2x1 - x2 + x3 + x4 -> max`

**Система обмежень:**
```text
2x1 -  x2 + 3x3 + 4x4 <= 10
 x1 +  x2 +  x3 -  x4 >= 5
 x1 + 2x2 + 2x3 + 4x4 <= 12
xj >= 0, j=1..4
```

## Приклад результату роботи програми
На виході програма генерує покроковий протокол (з відображенням симплекс-таблиць на кожній ітерації) і видає кінцеві результати:

* **Знайдено опорний розв’язок:**
```text
X = (5,00; 0,00; 0,00; 0,00)
```

* **Знайдено оптимальний розв’язок:**
```text
X = (0,00; 1,25; 3,75; 0,00)
```

* **Максимум функції мети:**
```text
Max (Z) = 2,50
```
