# Практична робота № 2: Розв'язання двоїстої задачі за допомогою модифікованих жорданових виключень

**Дисципліна:** Алгоритми систем підтримки прийняття рішень
**Виконав:** студент 3 курсу групи № 633П Коваленко М.А.

## Мета роботи
Навчитися будувати двоїсту задачу лінійного програмування і розв'язувати її за допомогою симплекс-методу та графічного методу.

## Функціонал програми
Для виконання практичної роботи було розроблено консольний застосунок мовою С#. Програма дозволяє автоматизувати такі дії:
* Прийом умов прямої задачі (кількість змінних, обмежень, цільова функція).
* Автоматичне математичне генерування та виведення на екран класичної постановки двоїстої задачі ($W \rightarrow \min$).
* Побудова спільної розширеної симплекс-таблиці з подвійними мітками для рядків та стовпців (прямі змінні `x/y` та двоїсті змінні `v/u`).
* Синхронне виконання кроків МЖВ з одночасним перерахунком обох задач та обміном подвійних міток.
* Коректне автоматичне зчитування векторів оптимальних розв'язків: для прямої задачі ($X$) та для двоїстої ($U$).

## Структура проекту
Програма побудована за принципами ООП та розділена на три основні класи:
* **`Program`**: відповідає за керування консольним інтерфейсом, збір вхідних даних (включаючи обробку знаків) та запуск обчислень.
* **`SimplexAlgorithm`**: інкапсулює математичну логіку. Містить алгоритми перетворення задачі, методи пошуку мінімальних відношень для спільної таблиці та логіку заміни базисних/небазисних змінних для обох задач одночасно.
* **`ConsoleHelpers`**: містить допоміжні методи для безпечної обробки вхідних даних та специфічного форматованого виведення подвійних симплекс-таблиць на екран.

## Вхідні дані (Варіант 12)
Програма приймає на вході пряму задачу (Z).

**Пряма задача (Z):**
`Z = -2x1 - x2 + x3 + x4 -> max`
при обмеженнях:
```text
 2x1 -  x2 + 3x3 + 4x4 <= 10
  x1 +  x2 +  x3 -  x4 <= 5
  x1 + 2x2 + 2x3 + 4x4 <= 12
xj >= 0, j=1,4
```

**Згенерована двоїста задача (W):**
`W = 10u1 + 5u2 + 12u3 -> min`
при обмеженнях:
```text
 2u1 -  u2 + 3u3 >= -2
-u1 +  u2 + 2u3 >= -1
 3u1 +  u2 + 2u3 >=  1
 4u1 -  u2 + 4u3 >=  1
ui >= 0, i=1,4
```

## Приклад результату роботи програми
Програма генерує покроковий протокол спільної симплекс-таблиці та видає кінцеві вектори:

* **Знайдено оптимальні розв'язки:**
```text
Розв’язки прямої задачі:
X = (0,00; 0,00; 3,33; 0,00)

Розв’язки двоїстої задачі:
U = (0,33; 0,00; 0,00)
```

* **Екстремуми функцій (Теорема двоїстості виконується):**
```text
Max (Z) = 3,33
Min (W) = 3,33
```
