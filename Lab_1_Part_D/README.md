# Практична робота № 1 Part D: Розв'язання задачі цілочислового лінійного програмування (метод Гоморі)

**Дисципліна:** Алгоритми систем підтримки прийняття рішень
**Виконав:** студент 3 курсу групи № 633П Коваленко М.А.

## Мета роботи
Навчитися розв'язувати задачу цілочислового лінійного програмування з використанням методу Гоморі

## Функціонал програми
Для виконання практичної роботи було розроблено консольний застосунок мовою С#. Програма дозволяє автоматизувати такі дії:
* Знаходження звичайного (дробового) оптимального розв'язку задачі лінійного програмування симплекс-методом (МЖВ).
* Автоматична перевірка знайдених значень змінних на цілочисловість.
* Виявлення змінної з максимальною дробовою частиною.
* Математичний розрахунок та генерування додаткового обмеження (відсічення Гоморі).
* Автоматичне додавання нового обмеження (рядка `s`) до поточної симплекс-таблиці та продовження ітерацій МЖВ до досягнення повністю цілочислового результату.
* Захист від зациклення алгоритму.

## Структура проекту
Програма побудована за принципами ООП та розділена на три основні класи:
* **`Program`**: відповідає за керування консольним інтерфейсом, збір вхідних даних (кількість змінних, обмежень, знаки нерівностей) та запуск циклу обчислень.
* **`SimplexAlgorithm`**: інкапсулює математичну логіку. Містить алгоритми пошуку опорного/оптимального розв'язків, метод виділення дробових частин чисел (`Math.Round` та `Math.Floor`) і логіку динамічного розширення матриці для додавання обмежень Гоморі.
* **`ConsoleHelpers`**: містить допоміжні методи для безпечної обробки вхідних даних та форматованого виведення симплекс-таблиць і рівнянь на екран.

## Вхідні дані
Програма приймає на вході кількість змінних і обмежень, коефіцієнти цільової функції `Z`, напрямок оптимізації (max/min), а також систему обмежень зі знаками (`<=`, `>=`, `=`).

**Приклад постановки задачі:**
`Z = c1*x1 + c2*x2 + ... + cn*xn -> max`
при заданій системі лінійних обмежень та умові `xj >= 0, xj ∈ Z` (цілі числа).

## Приклад результату роботи програми
Програма генерує покроковий протокол. Якщо перший знайдений розв'язок має дробові значення, програма виводить повідомлення та будує нове обмеження:

* **Знаходження дробового розв'язку:**
```text
Знайдено оптимальний розв’язок:
X = (0; 1; 4; 0)

Знайдено розв’язок, у якому змінні мають дробову частину, максимальна дробова частина у змінної: x3 = 3,75
```

* **Формування відсічення Гоморі:**
```text
Складено додаткове обмеження:
s1 = 0,75 * y2 + 0,75 * x1 + 0,25 * y1 + 0,75 * x4 + (-0,75) >= 0
```

* **Фінальний результат (після перерахунку):**
```text
Знайдено оптимальний розв’язок:
X = (0; 2; 4; 0)

Max (Z) = 2,00
```

## Реалізація в MS Excel
Додатково задачу було розв'язано в середовищі MS Excel за допомогою надбудови «Пошук рішення» (Solver). Для забезпечення цілочисловості оптимального плану до діапазону змінюваних клітинок було застосовано спеціальне обмеження типу **`целое` (int)**. Результати програмного розрахунку та табличної моделі повністю збігаються.
